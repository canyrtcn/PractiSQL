# Provider artwork / Sağlayıcı görselleri

The original SVG files are kept unchanged. Generated badge frames place them on a neutral white surface so they remain visible in both GitHub themes. Logos identify the providers and remain the property of their respective owners.

Özgün SVG dosyaları değiştirilmeden korunur. Üretilen çerçeveler, GitHub'ın iki temasında da görünürlük için nötr beyaz zemin kullanır. Logolar sağlayıcıları tanımlar ve ilgili sahiplerine aittir.

- **OpenAI:** [official Realtime Console artwork](https://github.com/openai/openai-realtime-console/blob/main/client/assets/openai-logomark.svg), [brand guidelines](https://openai.com/brand/).
- **Muse / Meta:** [official AI at Meta site](https://ai.meta.com/subscribe/), using the site's linked SVG application icon.
- **DeepSeek:** [official DeepSeek-V2 artwork](https://github.com/deepseek-ai/DeepSeek-V2/blob/main/figures/logo.svg).

`sources.json` records the original download URLs and SHA-256 values. These marks are not relicensed under the project's MIT license.
