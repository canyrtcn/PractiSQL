# Product presentation assets / Ürün sunum görselleri

The [presentation gallery](../showcase/index.html#presentation) contains 45 designs in English and Turkish, including six three-theme comparisons. Every interface view comes from a real application capture. The AI conversation is prepared demonstration content; SQL results and local checks were executed in the app. The workbook illustration uses actual generated PDF inner pages, not a mock document.

[Sunum galerisi](../showcase/index.html?lang=tr#presentation), altı üç-tema karşılaştırması dahil 45 tasarımın İngilizce ve Türkçe sürümlerini içerir. Arayüz görünümleri gerçek uygulama çekimleridir. AI konuşması hazırlanmış demo içeriğidir; SQL sonuçları ve yerel kontroller uygulamada çalıştırılmıştır. Çalışma kitabı görselinde gerçek PDF iç sayfaları kullanılır.

Regenerate with `npm run docs:showcase` followed by `npm run docs:showcase:render`. Generated HTML templates and verification files stay under ignored `artifacts/`. Committed PNGs, the gallery and the source manifest are the publication assets. The overview combines a real screenshot and the application’s native transparent vector mascot; screenshot pixels are not generated or repainted. The real PractiSQL wordmark font and icon are used. Keep accessible descriptions and demonstration-data context when embedding images.

Yeniden üretmek için `npm run docs:showcase`, ardından `npm run docs:showcase:render` çalıştır. Üretilen HTML şablonları ve kontrol dosyaları Git dışında `artifacts/` altında tutulur. PNG’ler, galeri ve kaynak manifesti yayıma yöneliktir. Genel görünüm kartı gerçek ekranı uygulamanın şeffaf zeminli gerçek vektör maskotuyla birleştirir; arayüz pikselleri üretilmemiş veya yeniden boyanmamıştır. Gerçek PractiSQL logo yazısı ve ikonu kullanılır. Görselleri eklerken erişilebilir açıklamaları ve demo verisi bilgisini koru.
