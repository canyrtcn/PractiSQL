# Promotional illustrations / Tanıtım görselleri

| Purpose / Amaç | English | Türkçe |
|---|---|---|
| Product overview / Uygulama tanıtımı | [overview.en.png](overview.en.png) | [overview.tr.png](overview.tr.png) |
| Learning workflow / Öğrenme akışı | [learning-workflow.en.png](learning-workflow.en.png) | [learning-workflow.tr.png](learning-workflow.tr.png) |

The overview combines a real demonstration screenshot with explanatory copy and an AI-generated mascot illustration. The learning visual uses the actual SQL editor and result table. Screenshot pixels are not generated or repainted. The exact local PractiSQL wordmark font and current application icon are used in both languages. Keep accessible alt text and the demonstration-data explanation when embedding them.

Uygulama tanıtımı gerçek demo ekranını açıklama ve AI üretimi maskot illüstrasyonuyla birleştirir. Öğrenme görselinde gerçek SQL editörü ve sonuç tablosu kullanılır. Ekran pikselleri yapay zekâyla üretilmemiş veya yeniden boyanmamıştır. İki dilde de gerçek yerel PractiSQL logo yazısı ve güncel uygulama ikonu kullanılır. Eklerken alternatif metni ve demo verisi açıklamasını koru.

The [presentation gallery](../showcase/index.html#presentation) contains 44 designs in English and Turkish, including seven three-theme comparisons. Regenerate them and these four README images with `npm run docs:showcase` followed by `npm run docs:showcase:render`.

[Sunum galerisi](../showcase/index.html?lang=tr#presentation), yedi üç-tema karşılaştırması dahil 44 tasarımın Türkçe ve İngilizce sürümlerini içerir. Yeniden üretmek için önce `npm run docs:showcase`, ardından `npm run docs:showcase:render` çalıştır.
