### English

- Fixed missing SQL function colours in the query editor. Functions such as `ROUND`, `AVG`, `SUM` and `COUNT` now use the same colour vocabulary as chat code blocks, including while typing and in large scripts.

Windows x64: download **Setup.exe** below. **.blockmap** and **latest.yml** support in-app updates; they do not need to be opened manually.

### Türkçe

- Sorgu editöründe SQL fonksiyonlarının renksiz görünmesi düzeltildi. `ROUND`, `AVG`, `SUM` ve `COUNT` gibi fonksiyonlar, yazarken ve büyük sorgularda da sohbet kod bloklarıyla aynı renk listesini kullanır.

Windows x64 için aşağıdaki **Setup.exe** kurucusunu indirin. **.blockmap** ve **latest.yml** uygulama içi güncellemeyi destekler; bunları elle açmanız gerekmez.
