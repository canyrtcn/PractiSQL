### English

- Improved responsiveness when editing large SQL scripts or typing in the AI conversation. Syntax highlighting stays enabled; incremental editing, background parsing and viewport rendering reduce work on the interface thread.
- Improved local SQL suggestions with table, alias, column and declared relationship context. Word, next-word, three-word and line modes now apply their selected completion length.
- Successful automatic SQL repairs no longer add internal error diagnostics to the final teaching explanation. Explicit debugging requests and unresolved errors remain visible.

Windows x64: download the **Setup.exe** installer below. The **.blockmap** and **latest.yml** files support in-app updates and do not need to be opened manually.

### Türkçe

- Büyük SQL sorguları düzenlenirken ve AI sohbetine yazılırken arayüzün akıcılığı iyileştirildi. Renklendirme açık kalır; değişen metnin işlenmesi, arka planda ayrıştırma ve görünür satırların çizilmesi arayüzdeki yükü azaltır.
- Yerel SQL önerileri tablo, takma ad, sütun ve tanımlı ilişkilerin bağlamını kullanacak şekilde iyileştirildi. Kelime, sonraki kelime, üç kelime ve satır modları seçilen tamamlama uzunluğunu uygular.
- Başarıyla tamamlanan otomatik SQL düzeltmelerinin iç hata açıklamaları son ders anlatımına eklenmez. Kullanıcının istediği hata incelemeleri ve çözülemeyen hatalar görünür kalır.

Windows x64 için aşağıdaki **Setup.exe** kurucusunu indirin. **.blockmap** ve **latest.yml** dosyaları uygulama içi güncellemeyi destekler; bunları elle açmanız gerekmez.
