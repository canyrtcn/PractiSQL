# PractiSQL 3.4.262

## English

PractiSQL brings a local SQL playground, AI-guided learning and structured practice into one desktop workspace.

### Included workflows

- Load SQLite databases, SQL dumps and CSV files; write and run SQL without an AI connection.
- Ask SQL questions, request a query for your schema, explain existing SQL and follow up on actual results.
- Use schema-based local completion, syntax highlighting, query plans, history and visual relationships.
- Follow guided lessons, solve challenges, practise SQL expressions and take AI-backed exams.
- Export database-based study workbooks and lesson explanations to PDF.
- Build data projects from documented sources and review SQL, numeric results and business interpretations.
- Choose Light, Leaf or Dark; use English or Turkish and adjust interface scale.

### Update behavior

New versions appear in the top notification panel with download progress and **Update now**. Installation requires explicit restart confirmation. Deferring does not install on normal exit, and failed checks leave a clear retryable status.

### Distribution status

This release is a preparation draft. No installer, blockmap or update metadata is attached. Windows x64 is the initial target; macOS is in preparation. The repository remains private. Its anonymous GitHub update feed is unavailable while private; no repository token is bundled with the application.

The current Windows build is unsigned. Review the README security note before installing a future attached package. Verified hashes and download instructions will accompany installer assets when approved.

## Türkçe

PractiSQL; yerel SQL playground, AI ile öğrenme ve düzenli pratiği tek masaüstü çalışma alanında birleştirir.

### Özellikler

- SQLite veritabanı, SQL dosyası veya CSV yükle; AI bağlantısı olmadan SQL yaz ve çalıştır.
- SQL hakkında soru sor, şemana uygun sorgu iste, hazır SQL’i açıklat ve gerçek sonuçlarla ilgili takip soruları sor.
- Şemaya dayalı yerel tamamlama, renklendirme, sorgu planı, geçmiş ve görsel ilişkilerden yararlan.
- Dersleri takip et, challenge çöz, SQL ifadelerini çalış ve AI destekli sınavlara katıl.
- Veritabanına dayalı çalışma defterini ve ders açıklamalarını PDF olarak sakla.
- Belgelenmiş kaynaklarla veri projeleri oluştur; SQL’i, sayısal sonuçları ve iş yorumunu incele.
- Açık, Yaprak ve Koyu temaları; Türkçe/İngilizce arayüzü ve ölçek seçimini kullan.
