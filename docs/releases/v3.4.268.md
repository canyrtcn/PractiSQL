### English

- Improved SQL completion context: sorting directions, expression positions and JOIN continuations now use the surrounding SQL grammar. Window clauses and nested queries keep their own context.
- Fixed multi-word suggestions so the selected mode also extends JOIN phrases and declared relationships. Accepting a suggestion preserves existing SQL after the cursor. Ambiguous tables and conditions are not invented.

Windows x64: download **Setup.exe** below. **.blockmap** and **latest.yml** support in-app updates; they do not need to be opened manually.

### Türkçe

- SQL tamamlamada bağlam takibi iyileştirildi: sıralama yönü, ifade konumu ve JOIN devamı çevresindeki SQL yapısına göre önerilir. Pencere fonksiyonları ve iç içe sorgular kendi bağlamlarını korur.
- Çok kelimeli öneriler, seçilen moda göre JOIN ifadelerini ve tanımlı ilişkileri de tamamlar. Öneriyi kabul etmek imleçten sonraki SQL'i korur. Belirsiz tablo ve koşullar uydurulmaz.

Windows x64 için aşağıdaki **Setup.exe** kurucusunu indirin. **.blockmap** ve **latest.yml** uygulama içi güncellemeyi destekler; bunları elle açmanız gerekmez.
