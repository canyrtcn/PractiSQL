### English

- Local SQL completion now recognizes SELECT output aliases in `ORDER BY` and `HAVING`, including quoted names and aggregate expressions. Suggestions stay within the current SELECT scope and preserve SQL after the cursor.

Windows x64: download **Setup.exe** below. **.blockmap** and **latest.yml** support in-app updates; they do not need to be opened manually.

### Türkçe

- Yerel SQL tamamlama, SELECT sonuç takma adlarını artık `ORDER BY` ve `HAVING` içinde tanır. Tırnaklı isimler ve toplama fonksiyonları desteklenir; öneriler mevcut SELECT kapsamını ve imleçten sonraki SQL'i korur.

Windows x64 için aşağıdaki **Setup.exe** kurucusunu indirin. **.blockmap** ve **latest.yml** uygulama içi güncellemeyi destekler; bunları elle açmanız gerekmez.
