### English

- Fixed severe typing and editor-resizing lag when large query results are visible. Result tables now render visible rows while preserving the complete result, sorting and cell copying.
- Fixed unwanted `SELECT * FROM` suggestions in empty editors and after finished queries. Improved alias handling inside SQL functions and removed unrelated suggestions where a value is expected. SQL highlighting and completion remain enabled.

Windows x64: download **Setup.exe** below. **.blockmap** and **latest.yml** support in-app updates; they do not need to be opened manually.

### Türkçe

- Büyük sorgu sonuçları açıkken yazma ve editörü köşesinden büyütme sırasında oluşan ciddi kasma düzeltildi. Sonuç tabloları, verinin tamamını, sıralamayı ve hücre kopyalamayı koruyarak görünür satırları çizer.
- Boş editörde ve tamamlanmış sorgudan sonra beliren gereksiz `SELECT * FROM` önerisi düzeltildi. SQL fonksiyonları içindeki takma adlar iyileştirildi; değer beklenen yerlerdeki alakasız öneriler giderildi. SQL renklendirmesi ve tamamlama açık kalır.

Windows x64 için aşağıdaki **Setup.exe** kurucusunu indirin. **.blockmap** ve **latest.yml** uygulama içi güncellemeyi destekler; bunları elle açmanız gerekmez.
