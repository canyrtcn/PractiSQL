# PractiSQL 3.4.263 — Bug fixes

## English

This maintenance build retains the update fixes delivered in 3.4.262 and verifies the normal release-upgrade route from 3.4.262 to 3.4.263. Application behavior is unchanged; the package version is advanced so existing installations can discover a real newer release.

- A new version appears in the top notification area with download progress and **Update now**.
- Installation requires explicit restart confirmation. Deferring does not install on normal application exit.
- Failed checks leave a retryable status. The installer preserves the existing application profile.
- Windows x64 installer, blockmap, update metadata and SHA-256 checksums are provided together.

The installer is unsigned. See the README security notice. The GitHub update feed is anonymous only while this repository is public; no repository token is distributed with the application.

## Türkçe

Bu bakım paketi, 3.4.262 ile gelen güncelleme düzeltmelerini korur ve 3.4.262’den 3.4.263’e normal release güncelleme yolunu doğrular. Uygulamanın işlevi değişmedi; mevcut kurulumların gerçek bir üst sürümü bulabilmesi için paket sürümü ilerletildi.

- Yeni sürüm üst bildirim alanında indirme ilerlemesi ve **Şimdi güncelle** ile görünür.
- Kurulum açık yeniden başlatma onayı ister. Erteleme, normal çıkışta kurulum başlatmaz.
- Başarısız denetim yeniden denenebilir bir durum gösterir. Kurucu mevcut uygulama profilini korur.
- Windows x64 kurucusu, blockmap, güncelleme metadata dosyası ve SHA-256 özetleri birlikte sunulur.

Kurucu imzasızdır; README’deki güvenlik notuna bak. GitHub güncelleme akışı yalnız repo public olduğunda anonim erişime açıktır; uygulamayla repo tokenı dağıtılmaz.
